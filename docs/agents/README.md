# Engagement 8 Agent Engineering

This folder owns the approved architecture, explanatory material, phase handoffs, and operator
runbooks for TrackFlow's LangGraph customer-experience agent.

- [`agent-design.md`](agent-design.md) is the owner-approved specification and takes precedence over
  bootcamp planning inputs.
- [`langgraph-explainer.md`](langgraph-explainer.md) explains the graph for maintainers.
- [`engagement-8-handoff.md`](engagement-8-handoff.md) records the Phase 0–2 implementation handoff.
- [`mcp-codespaces-runbook.md`](mcp-codespaces-runbook.md) covers Phase 3 OAuth client provisioning
  and the owner-review MCP Playground gate.

Implementation status is tracked in [`docs/briefs/08-agent-engineering.md`](../briefs/08-agent-engineering.md).
