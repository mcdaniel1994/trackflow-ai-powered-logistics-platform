# Public returns guidance

## Requesting a return

Request a return through the retailer or brand's portal. The brand defines eligibility rules. A return label may be generated automatically when the reason meets the brand's configured rules, such as wrong size or a defective product. TrackFlow's public chat cannot issue a return label or submit a return.

## Return window

The standard return window is 30 days from delivery, unless the customer brand has configured a different contractual window. Check the retailer's own policy before submitting a return.

## Return costs

The customer brand normally covers return shipping. If the reason is a TrackFlow error, such as damage in transit or wrong delivery, TrackFlow covers the cost. The applicable case must be reviewed through support; public chat cannot decide fault or approve a refund.

## International returns

International returns, purchased in one country and returned in another, require manual handling through TrackFlow support. They are not covered by the standard automated return process.
